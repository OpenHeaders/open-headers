# Support

## Where to ask

- **Questions & ideas** — [Discussions](https://github.com/OpenHeaders/open-headers/discussions).
- **Bugs & feature requests** — [Issues](https://github.com/OpenHeaders/open-headers/issues). The forms ask for your app, version, and OS — filling those in is the fastest path to a fix.
- **Security vulnerabilities** — email **security@openheaders.io**, never the public tracker. See [SECURITY.md](./SECURITY.md).

## Before filing a bug

1. Update to the latest release — the fix may already have shipped.
2. Search [existing issues](https://github.com/OpenHeaders/open-headers/issues?q=is%3Aissue) for the same problem; add a comment there instead of opening a duplicate.
