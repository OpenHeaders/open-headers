## Open source

- **Apache-2.0** — OpenHeaders Server is open source, built from the
  public repository at
  [github.com/OpenHeaders/open-headers](https://github.com/OpenHeaders/open-headers),
  where releases and the Docker image's source now live.

## Domains

- **openheaders.com** — the update feed, the license refresh
  endpoint, and every link the server prints moved from
  openheaders.io to openheaders.com. The old domain keeps serving, so
  running installs keep updating without any action.

## Fixes

- **Proxy tunnels to eager HTTP/2 servers** — an h2c server that
  sends its first frames immediately behind the proxy's CONNECT
  response could lose those bytes on Linux, failing the session with
  a protocol error. The tunnel handoff now pauses the socket while
  the leftover bytes are re-queued.
