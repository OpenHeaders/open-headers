## Scripts

- **Scripts read the send's own values** — for the sends the server
  resolves itself (CLI runs, MCP, chains), `oh.variables.get` and
  `oh.vault.get` answer from the resolution the send resolved with —
  its collection, environment and step captures — instead of the
  workspace's bare mirrors; a vault reference answers as `{{vault.ref}}`
  would.
- **A TOTP code a script reads is the send's usage** — the send is
  gated after the templates resolve and again after the pre-request
  chain, so a code still inside its window refuses the send before the
  wire, and a successful round trip records what the chain used beside
  the templates' codes.

## Sends

- **Unresolved variables ride as written** — an `{{unknown}}`
  reference no longer refuses a server-resolved send; it goes to the
  wire as the literal, and the result carries the list of references
  sent as written (the MCP send result includes it). Only a secret
  manager's typed failure refuses a send.
- **Failures carry their advice** — a classified failure (a name that
  does not resolve, a refused connection, TLS, a proxy leg, a pinned
  dial) separates the fact from what to check into two fields on the
  HTTP outcome and on the WebSocket, MQTT and gRPC session snapshots,
  so every client paints the advice under the error.

## Workspaces

- **The last workspace of an Org stays** — no device that sees the
  Org can delete its last workspace, and when a peer's delete empties
  the home Org the server re-seeds the default workspace instead of
  refusing and diverging from its clients.

## Fixes

- **Git sync** — git's auto-maintenance is pinned to the foreground so
  no detached git child writes to the repository after a command
  returned.
- **Dependencies** — the MCP SDK moves to 1.31.0 (an advisory on its
  OAuth client side; the server runs only the server side) and
  advisories close in the embedded web framework, the proxy's address
  parsing and the HTTP/3 helper's TLS library.
