## Runs

- **Headless suite runs** — a new execute tool runs collections,
  folders, and workflows on the server and answers a structured
  per-item report; clients that opt in receive live progress as items
  settle. It sits behind the `execute` opt-in (`mcp.allowExecute`)
  and powers the CLI's new `oh run`.

## Requests

- **HTTP version control** — server-run requests honor each request's
  HTTP version setting, including HTTP/3 over QUIC; a pinned version
  the target can't speak fails with a clear error, never a silent
  downgrade. The QUIC engine ships alongside the server binary.

## Proxy

- **Outbound proxy** — route the server's egress through a proxy:
  follow the standard `HTTP_PROXY`/`HTTPS_PROXY`/`NO_PROXY`
  environment variables, or set a manual proxy URL speaking HTTP,
  HTTPS, or SOCKS5. Configure it in the config file, via
  `OH_DAEMON_PROXY_*` variables, or with the `--proxy-mode`,
  `--proxy-url`, `--proxy-credential-ref`, and `--proxy-bypass`
  flags.
- **Applies everywhere** — request runs and the server's own calls
  (license refresh, audit forwarding) ride the same proxy; the bypass
  list follows curl's `NO_PROXY` semantics, and per-request proxy
  settings on a stored request still win over the server default.
