## Requests

- **HTTP version control** — request settings gain an HTTP version
  knob: sends forwarded to the desktop app can pin HTTP/1.1, HTTP/2,
  HTTP/2 (prior knowledge), or HTTP/3, with a clear error when the
  server can't speak the pinned version — never a silent downgrade.
  Sends from the browser keep the browser's own negotiation, shown as
  a browser-managed fact.
