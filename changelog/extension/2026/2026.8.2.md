## Open source

- **Apache-2.0** — OpenHeaders is open source. The extension is built
  from the public repository at
  [github.com/OpenHeaders/open-headers](https://github.com/OpenHeaders/open-headers),
  store submissions ship with a source archive, and contributions are
  welcome under the DCO. Vulnerability reports ride
  security@openheaders.com or GitHub private vulnerability reporting.

## Hardening

- **Web-visible surface shrunk** — the extension no longer exposes
  its pages, scripts, and styles to every website; the single
  redirect-delay page is the only web-accessible resource left. Sites
  can no longer detect the install by probing extension URLs or frame
  privileged pages.
- **Internal ports gated** — every internal message port now verifies
  the connecting realm belongs to the extension itself before
  attaching, so page-realm code cannot subscribe to another tab's
  streams or feed forged rows. Defense-in-depth; no behavior change.
- **Firefox** — the data-collection declaration required by
  addons.mozilla.org rides the manifest correctly, and the panel's
  value renderers were tightened alongside a one-time cache wipe.

## Domains

- **openheaders.com** — documentation links, in-app examples, and
  placeholder domains moved from openheaders.io to openheaders.com;
  the old domain keeps resolving.
