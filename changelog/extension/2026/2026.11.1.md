## Toolbar menu

- **Right-click the toolbar button** — **Open Workspace**,
  **Settings**, **Pause Rules** / **Resume Rules**, **Notifications**,
  and **Help** with Documentation, What's New and Report a Problem. The
  menu follows the language set in Settings. It uses the new
  `contextMenus` permission, for this button's menu only.

## DevTools panel

- **A request that ran with DevTools closed says so** — its Response
  and Preview read *Content is available only with DevTools opened, or
  with Debug mode on*, with the **Debug mode** switch under it, instead
  of loading forever.

## Desktop app

- **A long history no longer drops the connection** — a tab with a
  large log, watched from the desktop app, closed the connection to it.

## Fixes

- The timing popover no longer widens on a long request name.
- A rule update the browser refuses is no longer listed as an
  extension error; the rules status shows it, as before.
