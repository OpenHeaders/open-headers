## GraphQL

- **GraphQL requests** — a new request kind in the workbench tab
  beside HTTP, WebSocket, gRPC and MQTT. The header is the endpoint
  URL and a **Query** button (⌘/Ctrl+Enter), with an operation select
  once the document holds more than one; the tabs are Docs · Query ·
  Authorization · Headers · Schema · Scripts · Settings · Spec. Every
  operation posts the `{query, variables, operationName}` envelope as
  JSON from the browser, and the answer lands in the HTTP response
  pane with an `errors[]` tag in the error tone — a 200 with errors
  never reads as success — and an `extensions` tag whose popover
  shows the server's object verbatim.
- **Schema explorer** — the Query tab's left pane walks the resolved
  schema: the root operation types and their fields, any type's
  fields, arguments, enum values, input fields, interfaces and
  possible types, a search across type and field names, a
  descriptions toggle that persists, and *Insert at cursor*.
- **Query builder** — on the root page every field carries a checkbox
  that writes the document: selections by path, arguments as
  variables or typed literals (an input object expands to its input
  fields), union members and interface implementers as `... on T`
  rows, fragments read-only. A check under another operation type
  lands in that operation or appends a named one, and the operations
  the pick is not read dimmed in the editor. The document stays the
  source of truth — every gesture is an edit you can undo.
- **Editor** — completion, hover and diagnostics fed by the schema,
  Format on the toolbar, and a collapsible **Variables** drawer
  validated against the selected operation's definitions, with
  *Generate variables* from its declarations.
- **Schema sources** — introspection runs through the request's own
  authorization, headers and settings, shows when it was fetched and
  refreshes on demand; or link a GraphQL spec; or import an SDL or
  introspection file, which lands as a spec and links itself.
- **Subscriptions from the browser** — a picked `subscription` opens
  over WebSocket (`graphql-transport-ws`) from the tab itself: the
  session pane replaces the response pane with the subscription's
  phase — subscribing, subscribed, completed, stopped, error — and
  its events, and Query morphs to Stop, which sends *complete* and
  closes the session cleanly.
- **Specs and collections** — GraphQL joins the spec formats with an
  outline and validation; *Generate collection* from a schema asks
  for an endpoint (optional), makes one folder per root type and one
  request per root field with its document and example variables
  pre-filled, and links the collection to the spec so drift shows.
  A request's Spec tab reads its own link or its collection's.
- **Bridges** — the import hub takes a GraphQL schema file; a Bruno
  import brings GraphQL-typed requests as GraphQL requests; an HTTP
  request with a GraphQL body offers *Convert to GraphQL request*
  (same slot, saved responses kept); Copy as cURL; workflow steps
  run GraphQL requests; Save Response mints examples under the
  request.
- **On the tree** — GraphQL requests carry a `GQL` tag, and the
  collection's authorization pool, inherited settings and scripts
  (*Before query* / *After response*) apply as they do for HTTP.

## Backup and Sync

- **A settings root of its own** — Backup and Sync leaves
  Connectivity and sits over Sync, Desktop app and Advanced; the
  pages keep their ids, so every deep link still lands.
- **The Sync page in three bands** — a two-line card for this browser
  (*Learn more* as its tail); **Synced with** rows that read the
  place first, the state beside it and the address beneath, with
  Connect / Disconnect / Edit / Remove on the row's ⋯ menu and
  Re-pair inline; and **New workspaces › Where they go** as a row of
  its own. The diagrams and the tier cards are gone.
- **Connect desktop app** — the verb pairs over native messaging
  first and opens the dialog only when that fails, with the reason
  on its address step. **Sign in to a server…** opens the three-step
  dialog on an empty address: address › sign in › connect. The
  sign-in step reads its verdict off a probe — the server asks this
  device to pair, or the credential already signs in and the line
  names the server — with *Check again*, and a pairing that lands a
  token re-probes on its own. Nothing connects until the last step
  verifies the address and the sign-in.
- **Workspace sharing dissolves into the diff viewer** — the merge
  strategy row sits under Editor › Diff Viewer › Import preview;
  Version Control is Git alone.

## Places

- **Every workspace group reads as a place** — *This browser* for the
  home group, *This computer · desktop app* or *<name> · server* for
  a joined one — in the switcher's headers, the top-bar pill, the
  popup and panel pills, the status popover, the export preview's
  destination select and Manage workspaces. Only a warning state
  reads beside a header (not syncing, re-pair needed, disconnected,
  no longer syncing, connection removed — local copies). The
  switcher's reach ladder becomes one **Backup and Sync…** row, and
  grouped rows indent under their place.
- **Publish reads as Copy to <place>** — the dialog titles *Copy
  "<name>"*, names its target as the place, and its button reads
  *Copy to <place>*; the Duplicate form's destination follows.
- **The desktop app is its own port** — a server running on this
  computer on another port is a server in the switcher headers, the
  Sync rows, the status popover's companion row and the add-ons
  pill; it never passes for the desktop app.

## Authorization

- **A folder's rail picks from the pool** — an inheriting folder's
  select offers the *Inherited* group (the ancestor's entries; a pick
  reads one) over *This folder* (a type mints the folder's own first
  entry) in place of the Change dropdown; *Reset to inherited* is an
  icon-only undo.
- **Apply to host** reads *(optional)* after its label and its (i)
  explains the matcher: case-insensitive, `*` wildcard, exact host
  without one, port and path never count, empty means default only.
- **A drawn glyph per auth type** — a key, a password field, boxed B
  and H, a lock, a signature, the JWT pinwheel, a circled A with its
  version, the three vendor marks in colour — on the empty-state
  cards, the type menus and the entry rows.
- **The Authorization tab fills its pane** — the rail and the form
  scroll on their own with the divider the pane's full height, on a
  request and on a collection's pool alike; the sticky rail that slid
  before pinning is gone.

## Look and feel

- **Dark theme links** read in a pale tint of the accent instead of
  the duller mix the palette produced, with a lighter hover.
- **Go to jumps** carry a plain diagonal arrow.

## Fixes

- **Inline rename keys no longer grab the row** — typing in a rename
  no longer moves or selects the tree row, and the editor tabs of
  every request kind follow a rename.
- **See what's new** on the updated toast opens the What's New tab
  again; the button went stale once the tab list changed.
- **A connection still being added** stays off the Synced with rows,
  so no *Off* row shows behind its dialog.
