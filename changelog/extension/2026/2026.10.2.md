## Resilience

- **An error is contained where it happens** — a tab or tool window
  that fails shows *This tab hit an error* or *This tool window hit an
  error* with **Retry**, **Close tab** or **Hide window**, and the rest
  keeps working; a failed tab's close guard no longer offers a Save it
  cannot make. An error a surface cannot recover from shows one page in
  the extension's theme — *Reload to continue — your data is safe* —
  with **Reload** and **Copy details** (a green check confirms the
  copy). The popup, the devtools panel, the side panel and the
  workbench tab each carry their own funnel and fallback, so one
  surface failing never takes another with it, and every failure
  reaches the diagnostic log once: one line, the frames under it.

## Crash and error reports

- **A second anonymous channel, one switch of its own** — Settings ›
  General › Privacy gains **Crash and error reports** beside
  **Anonymous usage counting**, each independent of the other. When
  the extension crashes or hits an error it did not expect, a report
  says what kind of error it was and where in the extension's own code
  it happened: error class names, template ids (which standard engine
  message it matched, never its text) and positions in the extension's
  own files. No message and no install identifier — the random
  per-launch session id is all that groups reports — and nothing from
  a request, a rule, a script or a page can be expressed, because every
  string on the channel must match a fixed grammar. The service worker
  reports its own failures and carries the documents' on the same
  session; the same failure from the same place folds into one row per
  process and surface it fired in.
- **Readable byte for byte** — **View reports** opens the session
  inspector, now *Telemetry this session* with **Usage events** and
  **Error reports** as two tabs, each report exactly as sent or as
  suppressed. Turning the switch off holds reports already recorded in
  this browser: they leave only if the switch goes back on in the same
  session, and are discarded when the session ends; the usage switch
  keeps discarding as before.
- **The privacy policy, effective October 19, 2026** — names the
  channel in its sharing, endpoint and transparency lines; the
  wire-transparency document carries the envelope and the grammar
  table.

## Usage counting

- **Four coarse facts join the envelope** — the CPU architecture
  (`x64`, `arm64`, or `x64` running on an `arm64` machine), the
  operating-system and browser majors (macOS 15, Chrome 130 — never a
  build number), how the install keeps its workspaces (`local`,
  `server` or `git` — never where) and a fourteenth event: the size
  class a surface opened at (*at least 800 pixels wide*, never a
  size). The policy and the wire document list each.

## Help

- **Report Issue and Feature Request** — a dialog with a title and one
  description (the steps to reproduce for a bug, the workflow and the
  behavior you would like for a feature; Markdown welcome) and the
  system facts as a table behind **show**, with a checkbox to leave
  them out. **Preview on GitHub** opens a new issue with the title and
  one composed body; nothing is posted until you submit it there, and
  logs never ride the link — **Save bundle…** sits beside the notice.
  Your text is kept whole: when the link runs long the facts are
  trimmed first and the dialog says so; a text too long for any link
  asks you to shorten it here and add the rest on GitHub. It opens from
  Settings › About › Support (**Report…**, **Request…**) and from the
  notification timeline's **Bug Report or Feature Request** card on the
  popup, the panel and the workbench; a **Community Chat** card
  replaces the website nudge.
- **The diagnostic bundle** — Settings › Data › Diagnostics gains
  **Diagnostic Bundle › Save bundle…**: one ZIP with the diagnostic log,
  the status snapshot, this session's telemetry events and crash
  reports, your settings and the system facts, downloaded like any
  file and sent nowhere.

## Fixes

  a JSON body no longer runs before the language mode is set up, so the
  first pass is never rejected.
- **In-app docs** — two diagrams with a blinking terminal cursor kept
  the surface repainting while the Docs tab was shown; the cursors are
