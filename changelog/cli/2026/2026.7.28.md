## Runs

- **`oh run`** — run a collection, a folder, or a workflow headless
  from the terminal: `oh run collection Smoke --env staging`. Pick the
  output with `--reporter human|json|junit`, write it to a file with
  `--output`, and stop at the first failure with `--bail`. Requests
  run in sidebar order; a workflow run stays atomic — on failure the
  failing step reports `failed` and the rest `skipped`, never a
  phantom pass.
- **CI-ready** — exit codes are stable: `0` all passed, `1` run
  failed (the report is still emitted), `2` usage, `3` server
  unreachable, `4` denied. Works against a standalone server or the
  desktop app's embedded one; running sits behind the server's
  `execute` opt-in.
