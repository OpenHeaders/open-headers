## Commands

- **`oh request authorize <name-or-uid>`** — acquires a saved
  request's OAuth 2.0 token on the server it is connected to. Client
  credentials, password and JWT Bearer grants exchange at once; the
  device code grant prints the one-time code and the verification
  URL, polls at the provider's interval while you approve on any
  device, and reports the grant. A refusal, denial, expiry or failure
  exits 1 with the payload under `--json`; the authorization code
  grant is refused with the fix, since it needs a browser on the
  server.
