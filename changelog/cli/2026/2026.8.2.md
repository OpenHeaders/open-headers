## Open source

- **Apache-2.0** — `oh` is open source, built from the public
  repository at
  [github.com/OpenHeaders/open-headers](https://github.com/OpenHeaders/open-headers),
  where releases now publish.

## Domains

- **openheaders.com** — the install one-liners, the update feed
  behind `oh upgrade`, and the links `oh changelog` prints moved from
  openheaders.io to openheaders.com. The old domain keeps serving, so
  installed binaries keep updating without any action.
