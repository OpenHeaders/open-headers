## Requests

- **Path parameters** — a request's URL names its parameters as
  `:name` segments (a literal suffix such as `:id.json` is allowed), and
  the Params tab gains a **Path Parameters** table derived from the URL:
  a locked **Name** column, a value that may use `{{variables}}`, and a
  description. Values are substituted before the query is built, the
  variable scanner and the request fingerprint see them, and scripts
  read the resolved rows. A row without a value reads *unresolved* on
  the URL bar's dot, the Params tab and the sidebar badge, and sends as
  written. The `:name` token in the URL bar paints like a reference and
  opens its own hover card; the empty state asks for a `/:name` segment
  in the path.
- **Imports speak path parameters** — the OpenAPI, collection-file and
  folder-format importers emit `:name` URLs with the declared rows,
  and no longer inline example values or seed collection variables for
  them. Captured examples and **Save Response** carry the rows too.
- **The Spec tab and the Update dialog converge instead of rewriting**
  — a collection generated before path parameters moves to the `:name`
  form through your own apply as ONE change naming the URL and the
  path parameters — never a silent rewrite, never a remove plus an add.
- **Unresolved variables on every editor** — the MQTT, WebSocket, gRPC
  and GraphQL editors now read the footer pill, the tab dots and the
  target row's status from the same per-section scan the HTTP editor
  uses; the Variable Scope panel walks every request kind.
- **Dirty marks** — the count badge on an editor tab only ever counts,
  in the neutral fill; one dot beside it reads red for unresolved,
  salmon for unsaved and neutral for has-content.
- **Smaller things** — a `{{ref}}` split across tokens paints as one
  box; the URL bars share one placeholder idiom; the key/value grids'
  hairlines and focus ring are redrawn and a locked key cell stands as
  tall as a query row; the gRPC TLS toggle and the MQTT version select
  open their tooltips downward.

## Result panes

- **The send pulse** — one bar on the leading edge of every result
  pane sweeps while a send is in flight and lands in the status pill's
  tone. A stream is a session: an SSE response, a gRPC stream or a
  subscription rests on its tint from the head, sweeps one pass per
  message or publish, and lands by whose doing the end was — your own
  **Stop** or **Disconnect** neutral, the peer's close a warning, a
  refused message or a severed connection red. The empty states drop
  the spinner the pulse now carries.
- **Stop reads as a stop** — a gRPC Stop before the head is the neutral
  stopped row on the stream timeline and *1 CANCELLED* with the stop
  message on the unary pane, not a failure.
- **Clear actions** wear the trash icon in place of the broom; the
  lifecycle pill's Unresolved red reads muted on dark themes.
- **MQTT unsubscribe names the row** — toggling a subscription off
  unsubscribes exactly the filter it went up with, and a live-subscribed
  row's filter cell reads disabled.

## Sync

- **Every store boots from its log** — the workspace list and every
  per-workspace store hydrate by replaying the tab's durable log at
  startup, behind one gate every reader awaits; a change already in the
  log is never applied twice. The active workspace is remembered by
  this browser and never replicated.
- **Changes flushed on reconnect land whole** — a burst of changes made
  while the server was away applies there in the order they were made,
  and none are lost to a busy connection; a workspace joined from a
  snapshot streams only what the snapshot did not cover.

## Appearance

- **Light themes keep a light success tint** — status tags no longer
  take the muddy wash a dark seed derives.
- **The status and Add-ons popovers** — the status popover's rows sit
  in titled groups in a body sized to its content; the **Add-ons**
  popover groups its rows by place, the server row wearing the bound
  Org's icon.

## Help and diagnostics

- **The diagnostic bundle is anonymized** — every gathered part is
  redacted on its way into the archive: paths collapse to bracketed
  placeholders, URL credentials, credential-named query values and
  e-mail addresses go. The action now reads **Download anonymized
  diagnostic bundle…** and the README states what was removed.
- **Reporting** — the report dialog requires a title and a description,
  with the Markdown note under each field; the crash page offers
  **Report Issue** (seeded with the error) and **Community Chat**, and
  the crash survives Reload — the reloaded timeline offers the same two
  on a card. A contained error's button reads **Reload**.
