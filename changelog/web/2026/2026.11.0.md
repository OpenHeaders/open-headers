## Administration › Git

- **Value by value** — a pull or a merge lays the other side's change
  over the workspace: two edits to different values of one item both
  stand. Where both sides changed the same value, a dialog names the
  files by workspace item and offers **Accept Incoming**, **Keep Mine**
  or **Review Conflicts** in the merge editor.
- **Asked first** — uncommitted work in a file the pass writes is
  committed only on your word, with the files named; a file kept at
  your version is named in a toast.
- **A busy repository says so** — *Another Git process is using this
  repository* instead of a failure.

## Sync

- **A branch change is said** — when the server checks out another
  branch for a workspace, a toast names the workspace and the branch.
- **A deleted item can come back** — an item whose file returns in the
  server's folder (a rollback, a revert, a branch switch, a pull) is
  restored in every tab; an edit alone never brings one back.

## Workbench

- Every tree shares one multi-selection (Ctrl/Cmd, Shift, Shift+arrows);
  Settings reopens on the page you left; a dark dialog has an edge.
- **Settings search** — every word narrows the results, matches are
  highlighted, and a long result list no longer freezes the window.
- **Server Admin is now Administration** — the tool window, its tabs
  and every button that opens it; the role reads **Administrator**. Its
  rows are one line each and the row whose tab is open is marked; what
  each one covers is in the panel's (i). The **Server** row shows on a
  standalone server only.
