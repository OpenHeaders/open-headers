## Front door

- **Set up this server** — a fresh server greets the first browser
  with a setup form: create the account that administers the server
  and owns everything already on it. A browser on the server itself
  needs no code; a remote one enters the setup code the server printed
  as it started.
- **Sign in** — by the email and password the admin set, or with the
  configured identity provider; the token field left the page, and a
  server with no way to sign in says so instead of showing an empty
  form.
- **Awaiting access** — a signed-in user with no workspace yet sees
  an explained screen naming the server and the admin instead of an
  empty workbench; access arrives live when it is granted, and a
  revocation closes the tab's workspace at once.
- **Secure origin notice** — a tab served over plain HTTP from another
  machine explains what a secure origin unlocks, links the exact
  documentation pages, and points at the extension and the desktop
  app as the clients that reach the server directly.
- **Public workspaces** — a published workspace opens read-only under
  `/public` in this tab without an account, when the server allows it.

## Server Admin

- **One tool window, per-domain tabs** — Users, Devices, Git, Audit
  and Server as tabs of one dock panel; users can be created with
  their workspace access, made server admins, or created as service
  accounts; the workspace members modal grants and revokes peers,
  flips visibility and publishes a public snapshot after a review
  moment.

## The workbench

- **Everything in this release's desktop and extension notes** ships
  in the served tab too: MQTT requests over WebSocket, the thirteen
  authorization types with OAuth 2.0 device code, signed assertions,
  DPoP and OpenID discovery, authorization pools and inherited
  settings on collections and folders, scripts for WebSocket, MQTT and
  gRPC sessions, saved messages, the reworked session timelines,
  trusted certificates in three scopes, the sidebar's drag and drop
  and multi-select, and the redesigned Settings tree.
