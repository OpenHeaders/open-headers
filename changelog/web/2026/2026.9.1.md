## GraphQL

- **GraphQL requests** — the new request kind ships in the served tab
  with everything in this release's desktop notes: the schema
  explorer and the query builder, the schema-fed editor and the
  Variables drawer, GraphQL specs with *Generate collection*, the
  Spec tab, the import bridges and *Convert to GraphQL request*.
  Queries, mutations, introspection and subscriptions run through
  the server that serves the tab, so its trust and proxy settings
  apply.

## Backup and Sync

- **A settings root of its own** — Backup and Sync leaves
  Connectivity; the pages keep their ids, so every deep link still
  lands.
- **The Sync page reads this server** — a card for *This server*
  (your workspaces live here; every browser and device that signs in
  works on the same copies), one **Synced with** row naming the
  server with who is signed in beneath and *Administer…* on its ⋯
  menu for an admin, and **New workspaces › Where they go**. The
  diagrams and the tier cards are gone.
- **Workspace sharing dissolves into the diff viewer** — the merge
  strategy row sits under Editor › Diff Viewer › Import preview;
  Version Control is Git alone.

## The workbench

- **Every workspace group reads as a place** — *<name> · server* in
  the switcher's headers and the top-bar pill, with only a warning
  state beside it; the switcher's reach ladder becomes one **Backup
  and Sync…** row; Publish reads as **Copy to <place>**.
- **Authorization polish** — a folder's rail picks from the inherited
  pool, *Apply to host* reads *(optional)* with an (i) on the
  matcher's rules, a drawn glyph per auth type, and the Authorization
  tab's rail and form scroll on their own.
- **Look and feel** — dark theme links in a pale tint of the accent;
  Go to jumps carry a plain diagonal arrow.
- **Fixes** — inline rename keys no longer grab the tree row and
  editor tabs follow a rename; a connection still being added stays
  off the Synced with rows.
