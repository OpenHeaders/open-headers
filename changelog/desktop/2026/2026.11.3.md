## Windows

- **A Windows package (MSIX)** — a new way to install on a PC that has
  no Open Headers yet: it installs in seconds and updates through
  Windows.
- **A small installer for Windows** — one small file to download: it
  shows its download's progress and installs in seconds.
- **A package update restarts in seconds** — the app closes as soon as
  Windows has the update and comes back on the new version.
- **A package update shows its progress** — the Updates page shows a
  bar with the percentage while Windows fetches the update.
- **Pairing by itself on Windows on ARM** — the browser extension
  connects to the desktop app with no pairing step, as it does on
  every other platform.
- **MCP setup names the app where it is** — the command a client is
  given points at this install's own program.
- **The command line stays connected between installs** — the CLI
  keeps its connection when the app's data goes to the Windows package
  or comes back from it.

## Platform

- **A start that needs less from the system** — the app starts in full
  on a system that gives it no process figures.
- **The update button stands apart** — Update & Restart has a colour of
  its own, and the Updates page leads with its settings.
