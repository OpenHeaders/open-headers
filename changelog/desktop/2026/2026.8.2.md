## Open source

- **Apache-2.0** — OpenHeaders is open source. This is the first
  release built from the public repository at
  [github.com/OpenHeaders/open-headers](https://github.com/OpenHeaders/open-headers),
  and the release itself is published there — the code and the
  binaries now live in the same place. The full application history
  is public, and contributions are welcome under the DCO.
- **Security policy** — vulnerability reports ride
  security@openheaders.com or GitHub private vulnerability reporting
  on the repository; the
  [security policy](https://github.com/OpenHeaders/open-headers/blob/main/SECURITY.md)
  carries a safe harbor for good-faith research and the release
  signing key for verifying downloads.

## Domains

- **openheaders.com** — the website, documentation, update feed, and
  every in-app link moved from openheaders.io to openheaders.com. The
  old domain keeps serving indefinitely, so existing installs keep
  updating and old links keep resolving — nothing to do.

## Fixes

- **Proxy tunnels to eager HTTP/2 servers** — an h2c server that
  sends its first frames immediately behind the proxy's CONNECT
  response could lose those bytes on Linux, failing the session with
  a protocol error. The tunnel handoff now pauses the socket while
  the leftover bytes are re-queued.
