## Fixes

- **rpm upgrades keep the `openheaders` command** — upgrading the rpm
  from an older install could drop the launcher symlink when the
  outgoing package's cleanup ran after the new install; the install
  scripts now re-assert the command once the upgrade completes, so it
  survives every upgrade path.
