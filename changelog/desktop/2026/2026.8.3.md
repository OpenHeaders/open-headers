## Linux

- **Signed apt repository** — installing the deb registers the
  OpenHeaders apt repository, so future versions arrive through
  `apt upgrade` like any other package. The repository is signed with
  a dedicated archive key whose fingerprint is published in the
  [security policy](https://github.com/OpenHeaders/open-headers/blob/main/SECURITY.md);
  set `OPENHEADERS_ADD_REPO="false"` in `/etc/default/openheaders`
  before installing to opt out, and removing the package deregisters
  the repository again.
- **Signed rpm repository** — installing the rpm registers the
  OpenHeaders dnf repository the same way, signed with the same
  archive key; the `OPENHEADERS_ADD_REPO="false"` opt-out and
  removal deregistration apply identically.
- **Update notifications for package-manager installs** — deb and rpm
  installs now check the update feed and say so in the app — the
  update toast, the menus, and the Settings row point at your package
  manager when a new version is out. The app never downloads or
  installs updates itself on these installs; your package manager
  stays the only thing that touches the binaries.
- **Launcher window association** — the installed desktop entry now
  matches the application's window class, so docks and taskbars link
  running windows to the launcher entry reliably.
