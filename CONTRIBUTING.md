# Contributing

Open Headers is proprietary software; this repository is its public home
for downloads, documentation, and feedback. It does not contain the
source code, and **we do not accept contributions or pull requests** —
any PR opened here will be closed.

What we do welcome:

- **Bug reports and feature requests** — file an
  [issue](https://github.com/OpenHeaders/open-headers/issues) using the
  forms.
- **Questions & ideas** — open a
  [Discussion](https://github.com/OpenHeaders/open-headers/discussions).
- **Security reports** — email **security@openheaders.io** (see
  [SECURITY.md](./SECURITY.md)).

By participating you agree to the
[Code of Conduct](./CODE_OF_CONDUCT.md).
