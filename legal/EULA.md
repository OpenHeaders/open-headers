## 1. Definitions

- **Active User** — a user record in an active (non-deactivated) state
  in a daemon deployment's user directory.
- **Free Tier** — use of the Software without a License File, limited
  to 6 Active Users per daemon deployment.
- **Individual Seat License** — a License File issued to a named
  individual (the "holder") that records the holder's email address
  and admits that individual, and only that individual, as one Active
  User in a daemon deployment that has reached its seat limit.
- **License File** — a cryptographically signed artifact issued by
  Bithub Team that records the licensed seat count and validity period.
- **Seat** — the right for one Active User to be provisioned in a
  daemon deployment.

## 3. License Files, verification, and lapse

The Software verifies License Files entirely offline. Self-serve
License Files are renewed automatically over a documented,
publicly-specified network call; enterprise License Files may be
delivered and renewed manually for offline or air-gapped use.

If a subscription lapses or a License File expires, the Software
**never locks you out and never withholds your data**: after a grace
period, seat limits revert to the Free Tier for newly provisioned
users only. Existing users continue to sign in and existing data
remains fully accessible and exportable.
