# Open Headers

![Open Headers Logo](./src/assets/images/icon128.png)

Open Source DevToolkit inside a browser extension — modify live
browser requests, manage API collections, collaborate with your team.

Local-first: no account, no cloud, your data stays on your machine.

## What it does

The extension is the full toolkit, standalone in the browser:

- Nine rule types over live browser traffic — headers, redirects,
  response overrides, and more
- DevTools-grade network panel with request/response inspection
- Full API client — HTTP, GraphQL, gRPC, WebSocket, OAuth 2.0, scripts
- Workflows with chained & scheduled requests
- Encrypted vault for secrets and tokens
- Multi-workspace team collaboration
- MCP server for AI tooling
- Works offline; pairs optionally with the desktop companion for
  git-backed sync, dynamic value sources, and a local proxy

## Quick Start

1. Install the extension from your browser's store:
   - [Chrome](https://chromewebstore.google.com/detail/ablaikadpbfblkmhpmbbnbbfjoibeejb)
   - [Edge](https://microsoftedge.microsoft.com/addons/detail/open-headers/gnbibobkkddlflknjkgcmokdlpddegpo)
   - [Firefox](https://addons.mozilla.org/en-US/firefox/addon/open-headers/)
2. Optional: install the desktop companion from
   [Releases](https://github.com/OpenHeaders/open-headers/releases) —
   the extension connects to it automatically
